# Spec template

Copy to `docs/specs/YYYY-MM-DD-short-name.md` before non-trivial implementation.

## Goal

What this change achieves. What is explicitly out of scope.

## Approach

Chosen design. Why not the obvious alternative.

## Files

List of files to create or modify.

## Verification

Exact commands and manual checks that prove done:

```bash
# example
.venv/bin/python -m pytest tests/test_foo.py -v
```

## Rollback

How to revert if wrong (if non-obvious).
